# iPhone Atlas — экраны и визуальная спецификация

22.10.2026 · Концепт 0.2 · Рабочее название.

14 изображений: 10 основных страниц, 2 дополнительных вида страницы backup, подтверждение удаления и лист из четырёх важных состояний. Все PNG имеют размер 1536×1024. Это сгенерированные макеты с вымышленными данными, а не снимки работающего приложения. Ссылки, цифры, иконки и копирайт на PNG не заменяют продуктовые контракты [плана](PROJECT-PLAN-RU.md).

Просмотр всего комплекта: [галерея](DESIGN-GALLERY.html). Генерация выполнена встроенным ImageGen; [исходные промпты и точечные исправления](IMAGE-PROMPTS.json) сохранены для дальнейшей работы. Итоговые файлы находятся в `mockups/`; исходные варианты не входят в поставляемый набор.

## Направление

Простой нативный macOS-инструмент: боковая навигация как у файлового приложения, большие спокойные рабочие области, таблицы для сравнимых значений, миниатюры только для медиа. Главный акцент — сами данные и ясное происхождение, а не визуальная «оценка здоровья» устройства.

| Параметр | Решение для реализации |
|---|---|
| Основной фон | Системный window/content background; светлый reference #FFFFFF |
| Sidebar | Системный sidebar material, reference #EEF0F3 |
| Текст | Системный label, reference #202124 |
| Вторичный текст | Secondary label, reference #6B7280; проверять contrast в обеих темах |
| Акцент | Системный blue, reference #2868C7 |
| Разделители | Separator, reference #DDE1E6 |
| Шрифт | Системный SF; monospaced только пути, hashes, технические значения |
| Рабочие размеры | Body 13–15 pt, heading 22–28 pt, отступы 20–24 pt |
| Скругления | Системные контролы; ограниченные контейнеры 10–12 pt |
| Анимация | Только ответ на действие; уважать Reduce Motion |

Макеты крупнее типичной плотности native UI ради чтения в чате. Их не следует буквально переводить в points. Системная светлая/тёмная тема обязательна; отдельный комплект dark-концептов в этой версии не генерировался. В реальной реализации использовать доступные системные символы; нарисованные генератором логотипы сторонних приложений не являются готовым лицензированным asset pack.

## Точное поведение, важнее иллюстрации

- При отсутствии телефона пункты live-device сохраняются в навигации, но ведут к инструкции подключения; backup не блокируется.
- Обзор не суммирует перекрывающиеся категории. Заполненная полоса — только сопоставимые used/free одной метрики; более глубокая детализация появляется после доказательства её смысла.
- В простом режиме происхождение доступно кнопкой «Сведения»; развёрнутый технический инспектор на 07/11 иллюстрирует Advanced.
- `—` означает недоступность/неизвестность, а не ноль. Счётчики categories могут быть partial; число сообщений и число диалогов подписываются раздельно с корректной локализацией склонений.
- На 12 denominator проверки файлов в реализации включает только записи с ожидаемым файловым payload; каталоги и ссылки учитываются отдельно. Числа на картинке не задают схему счётчиков.
- «Сохранить исходник» у SQLite предлагает понятный выбор: DB вместе с найденными WAL/SHM и manifest либо отдельный явно обозначенный файл. Незавершённый/несогласованный комплект нельзя выдавать за целую базу.
- На 09 точная финальная подпись: «Удаление не выполнялось» и отдельное «Свободное место: повторный замер не выполнялся» либо реальное before/after. Экспорт не доказывает причинность фонового изменения свободного места.
- На 14 после disconnect сначала проверить источник и актуальность, затем решать возможность продолжения; автоматический resume не гарантируется. При missing payload остальные результаты также сохраняют собственные статусы проверки.
- Unsupported artifact позволяет raw fallback только при доступном envelope и payload; неподдержанный Manifest/keybag не обещает просмотра расшифрованных файлов.
- Переключатель «Индексы содержимого» должен иметь однозначную положительную подпись «Сохранять индекс содержимого», off по умолчанию. Создание по запросу и срок хранения описываются отдельно.
- Кнопка подготовки удаления на 04 и sheet 13 — проектируемое расширение O02, скрытое либо объяснимо недоступное в read-only beta. Галочка не заменяет проверку capabilities, identity, export receipt и актуальности объекта.
- Имена/содержимое на изображениях синтетические. Ни реальные serial/UDID, ни пользовательские пути в макеты не включались.

## Состояния и взаимодействие

Каждая таблица: loading, partial, empty, access denied, error, cancelled, stale. Пустой список сначала объясняет результат проверки; не выдаёт отказ доступа за отсутствие данных. Ошибки остаются локальными к источнику.

Длинные действия показываются в «Операциях», но человек продолжает просматривать готовые результаты. Отмена останавливает новые работы и сообщает судьбу уже начатых. Подтверждение привязано к неизменяемому составу; новый выбор аннулирует прежнее согласие.

Поиск сначала ограничен текущей областью. Для полного поиска по содержимому нужен отдельный явно запущенный индекс. По мере готовности UI объясняет, какие разделы уже просмотрены; не показывает произвольный процент «всего iPhone».

При ширине меньше достаточной для четырёх колонок inspector убирается в переключаемую панель; выбранная запись и breadcrumb сохраняются. Tab order следует чтению слева направо; критические действия не зависят от hover. Все символы имеют accessible labels; warnings дублируются текстом.

## Следующая итерация дизайна

После обратной связи выбрать плотность таблиц и ширину inspector, уточнить рабочее название. Затем перевести принятые страницы в SwiftUI fixtures и проверить живые layout, клавиатуру и VoiceOver. Pixel-точная реализация не должна наследовать случайные особенности генерации. Сейчас принимается направление и полнота навигации, не работающий UX.
